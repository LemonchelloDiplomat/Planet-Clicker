# 🌍 Planet Clicker

**Planet Clicker** — учебная игра-кликер, разработанная на **C# и Unity** и опубликованная в браузере с использованием **WebGL**.

🎮 **Играть:** https://lemonchellodiplomat.github.io/Planet-Clicker/

## 🎯 О проекте

Игрок получает игровую валюту за клики, покупает улучшения и новые планеты, а также развивает автоматическое получение ресурсов.

Проект был создан для практики разработки игровой логики, пользовательского интерфейса, систем прогресса и интеграции внешнего SDK.

## ⚙️ Основные возможности

* 🖱️ Получение игровой валюты за клики
* 🛒 Магазин улучшений
* ⬆️ Система улучшений
* 🤖 Автоматическое получение ресурсов
* 🪐 Покупка и открытие новых планет
* 💾 Система сохранения прогресса
* 🎵 Музыка и игровые ресурсы
* 🔐 Авторизация
* 📺 Рекламная интеграция через Yandex SDK
* 🌐 WebGL-версия для запуска игры в браузере

## 🛠️ Технологии

* **C#**
* **Unity**
* **Unity WebGL**
* **Yandex SDK**

## 📚 Цель проекта

Проект создавался в учебных целях для получения практического опыта в:

* разработке игровой логики на C#;
* создании пользовательского интерфейса;
* работе с игровыми системами и прогрессом;
* реализации сохранений;
* интеграции внешних SDK;
* сборке и публикации проекта в формате WebGL.
