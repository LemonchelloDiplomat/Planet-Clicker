# 🌍 Planet Clicker

Учебный проект игры-кликера на C#.

Игрок развивает планету, получает игровую валюту, покупает улучшения и открывает новые планеты.

## 🎮 Play

**[Play Planet Clicker](https://lemonchellodiplomat.github.io/Planet-Clicker/)**

## 🛠 Technologies

* C#
* WPF
* Yandex SDK

## ✨ Features

* Система кликов и игровой валюты
* Магазин улучшений
* Улучшение эффективности получения ресурсов
* Автоматическое получение ресурсов
* Открытие новых планет
* Несколько игровых экранов
* Сохранение прогресса
* Музыкальное сопровождение
* Авторизация
* Рекламная интеграция

## 🎯 Project Purpose

Проект был создан для практики разработки приложений на C#, работы с интерфейсами, игровой логикой, сохранением данных и интеграции внешнего SDK.

При разработке использовались AI-инструменты в качестве вспомогательного средства для поиска решений и работы с кодом.
